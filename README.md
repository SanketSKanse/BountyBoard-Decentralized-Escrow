# BountyBoard

BountyBoard is a Web3 freelance marketplace where clients publish work, lock rewards in smart-contract escrow, and pay freelancers through milestone-based releases.

## Architecture

```text
client (React + Vite)
  | HTTP for metadata and indexing
  | ethers.js / wallet provider for user-signed blockchain transactions (Phase 7+)
  v
server (Express + Prisma) <--> PostgreSQL

contracts (Hardhat + Solidity)
  | authoritative escrow, permissions, milestones, disputes, and ETH movement
  v
local Hardhat network
```

The database stores searchable marketplace metadata and cached blockchain information. It is never the source of truth for escrow balances or payment execution. Users sign blockchain transactions in their wallet; the backend does not control user wallets.

## Technology choices

- **Client:** React, Vite, TypeScript, Tailwind CSS
- **Server:** Express, TypeScript, Prisma, PostgreSQL
- **Contracts:** Solidity, Hardhat, ethers.js
- **Local chain:** Hardhat Network
- **Package management:** npm workspaces

## Project structure

```text
client/       React application and future web3 adapter
server/       REST API, Prisma schema, and indexing services
contracts/    Solidity contract, Hardhat config, scripts, and tests
```

## Prerequisites

- Node.js 20 or newer
- npm 10 or newer
- PostgreSQL 16 or newer for Phase 3
- MetaMask for Phase 7+

## Install

```bash
npm install
```

Copy environment examples when each phase needs them:

```bash
cp client/.env.example client/.env
cp server/.env.example server/.env
cp contracts/.env.example contracts/.env
```

## Phase 1 commands

Run type checks and builds:

```bash
npm run typecheck
npm run build
```

Run the client and API together:

```bash
npm run dev
```

The client runs on the Vite URL printed in the terminal. The API health endpoint is `http://localhost:4000/health`.

## Later development commands

Start a local blockchain:

```bash
npm run dev:chain
```

Deploy contracts after the contract phase is implemented:

```bash
npm run deploy:local
```

Run contract tests:

```bash
npm run test:contracts
```

Set up PostgreSQL after the Prisma phase is implemented:

```bash
npm run db:generate
npm run db:push
```

## Development roadmap

1. **Phase 1:** Monorepo foundation and service configuration.
2. **Phase 2:** Responsive marketplace UI with clearly labeled mock data.
3. **Phase 3:** Express REST API, Prisma models, validation, and PostgreSQL.
4. **Phase 4:** `BountyEscrow` contract with state transitions, milestones, and disputes.
5. **Phase 5:** Hardhat security and behavior tests.
6. **Phase 6:** Local deployment and contract address configuration.
7. **Phase 7:** MetaMask connection, network detection, and balance display.
8. **Phases 8-13:** Signed bounty creation, escrow funding, freelancer workflow, payments, disputes, and event indexing.
9. **Phases 14-15:** UX polish and a repeatable hackathon demo flow.

## Web3 learning model

For a future funding action, React will call an adapter in `client/src/web3/`. ethers.js will ask MetaMask to sign a transaction. The local chain will execute `BountyEscrow`, update on-chain state, emit an event, and return a transaction hash. The server will index that event and cache it for queries, while the contract remains authoritative.

## Security notes

Never commit private keys or real secrets. Local development should use only accounts generated by Hardhat. Contract permissions and payment rules must be enforced in Solidity, not only in frontend controls.
